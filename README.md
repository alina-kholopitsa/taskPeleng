Обработчик в качестве параметров принимает остаток строки, идущий после серии пробельных символов, как const char*. 
Комманды "date" и "time" в качестве параметра могут принимать соотвественно дату (в одном из следующих форматов: DD-MM-YYYY, DD.MM.YYYY или DD,MM,YYYY) и 
время (в одном из следующих форматов:HH:MM:SS, HH.MM.SS или HH,MM,SS). Если данные введены корректно - то в консоле появится сообщения, что дата (время) 
введены корректно и выведется введенная дата (время) в консоль.
Остальные комманды не предусматривают обработки параметров, поэтому, если в одну из этих комманд передается параметр, то в консоль выводится сообщения типа:
"Для завершения работы программы введите команду 'exit' без параметров.".
